## Prompt 1 — Setup (free tools only)

Set up an AI video editor in a folder called "AI video editor" on this
machine. Install only free tools — FFmpeg for cutting/encoding and Whisper
for subtitles/transcription — and verify each one works. Create subfolders
for raw footage, reference reels, and finished drafts. Do not use any paid
tool. Report what was installed and what is ready.

## Prompt 2 — Learn my editing style from references

Study every reference reel in the references folder and learn my editing
style from them: how cuts are placed, where B-rolls go, how subtitles look
and read, how sound is used, and the overall pacing. Write a short style
guide from what you learned, and use that style guide for every edit from
now on. The more context you have about how I edit, the better each draft
should get.

## Prompt 3 — Cut my video, beat by beat, with my approval

Take my raw A-roll and cut it in my learned style: cuts, B-rolls,
subtitles, and sound. First give me a storyboard to review. Then produce
the draft, one beat at a time, on an approval dashboard: I approve or reject
each beat and give feedback, and you give me the next draft based on that
feedback. Repeat until the video is perfect. Never publish a draft I have
not approved.

## Prompt 5 — Motion-style skills (use these styles in every video)

Use these motion styles, choosing the one that fits each beat best, and
tell me which style you used for each beat:

1. Smooth zoom — slow zoom in on the hero moment, zoom out for reveals.
2. Punch zoom — fast zoom punch on a big moment (six, wicket, reaction).
3. Shake — short shake on impact beats, never on calm beats.
4. Slide / wipe transitions — clean slide or wipe between scenes, no
   random effects.
5. Kinetic text — key words pop/slide on screen in time with the voice,
   big and readable, never covering faces.
6. Speed ramp — slow motion on the peak moment, normal speed around it.
7. Flash cut — quick white flash cut on hard scene changes.
8. Pan / Ken Burns — slow pan across still pictures so photos feel alive.

For every video, list the motion style used per beat in the storyboard,
so I can approve or change each one before the final cut.
